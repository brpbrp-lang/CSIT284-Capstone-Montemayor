## Project Description

A Flutter-based class schedule viewer designed for **BSIT 3-A** students. The app provides a clean, mobile-first interface for viewing the section's fixed block schedule and managing personal additional subjects such as overload units, meetings, or other events.

### Key Features

- **Today View** — See today's classes at a glance with a live "Up Next / Now Happening" hero card and auto-refreshing countdown timer.
- **Weekly View** — Browse the full week schedule with horizontal day capsule tabs and a 5-Day / 7-Day toggle.
- **Add Subject** — Students can add personal subjects, meetings, or events outside the standard block schedule.
- **Class Details** — Tap any class card to view full details (time, room, instructor) with options to edit or remove added subjects.
- **Color-Coded Subjects** — Each course is assigned a unique color theme for quick visual identification.

### Tech Stack

- **Framework:** Flutter (Dart)
- **State Management:** InheritedWidget (`ScheduleScope`)
- **Target Platform:** Web (with phone-frame preview)
